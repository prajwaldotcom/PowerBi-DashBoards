# Sales Performance Dashboard

## Overview

The **Sales Performance Dashboard** is an interactive Power BI project that provides a clear view of business sales, profit, and customer performance. It helps users monitor key metrics, identify trends, and make informed business decisions using visual reports.

## Key Features

* Interactive and user-friendly dashboard
* KPI cards for Sales, Profit, and Orders
* Sales analysis by Category and Region
* Trend analysis using charts and graphs
* Dynamic filters (Slicers) for better insights

## Tools Used

* **Power BI Desktop**
* **Power Query**
* **DAX**
* **Data Visualization**

## Benefits

* Monitors business performance in real time
* Identifies top-performing products and regions
* Supports data-driven decision making
* Simplifies complex sales data with interactive visuals

## File

* **Sales performance.pbix** – Power BI dashboard project.

## Conclusion

This dashboard transforms raw sales data into meaningful insights through interactive visualizations. It enables businesses to track performance, analyze trends, and make better strategic decisions efficiently.
